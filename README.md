# Shuter

## Назначение

Динамичный космический шутер на Pygame: игрок управляет ракетой, сбивает НЛО, избегает астероидов и старается набрать целевой счёт.

## Игровая механика

- стрелки влево/вправо двигают ракету;
- пробел выпускает пулю;
- после пяти выстрелов включается трёхсекундная перезарядка;
- победа — 20 сбитых кораблей;
- поражение — три столкновения или десять пропущенных врагов;
- игра автоматически перезапускается после завершения раунда.

## Структура

```text
shooter_game.py  # игровой цикл, спрайты и столкновения
galaxy.jpg       # фон
rocket.png        # игрок
ufo.png           # враг
asteroid.png      # препятствие
bullet.png        # снаряд
space.ogg         # музыка
fire.ogg          # звук выстрела
```

## Установка и запуск

```bash
pip install pygame
python shooter_game.py
```

Запускайте скрипт из папки репозитория, чтобы он нашёл графику и аудио.

## Технологический стек

- Python
- Pygame
- спрайты, столкновения, звук и игровой цикл

## Статус и ограничения

Это завершённый по основному циклу аркадный прототип. Нет стартового экрана, меню настроек и сохранения рекорда; полезным следующим шагом будет разделить код на модули и добавить экран начала новой игры.
